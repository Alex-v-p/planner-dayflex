# Release checklist

- [ ] Release notes are prepared
- [ ] Release PR source is `develop` and target is `main`
- [ ] `develop` is current with all intended ticket PRs
- [ ] CI passed for the release PR
- [ ] Next version follows `docs/architecture/versioning.md`
- [ ] Version source, changelog, and Git tag agree
- [ ] Database migrations are identified
- [ ] Required configuration changes are documented
- [ ] Deployment workflow and target are confirmed
- [ ] Post-deploy verification steps are listed
- [ ] Rollback approach is understood
