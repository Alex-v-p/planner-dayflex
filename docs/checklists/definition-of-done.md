# Definition of done

A ticket is done when:

- [ ] Acceptance criteria are complete
- [ ] Relevant tests are added or updated
- [ ] Lint/format checks pass
- [ ] Build passes
- [ ] CI passes
- [ ] No P0/P1 review findings remain
- [ ] PR description explains what changed
- [ ] Data-model impact is explicitly listed as added, changed, removed, or None
- [ ] Service and container impact is explicitly documented, including None
- [ ] Container/topology checks pass when Docker or Compose changed
- [ ] Manual verification steps are listed
- [ ] Human owner has reviewed the final diff
